Institutional Profile

Government Engineering College, Mosalehosahalli

Hassan District, Karnataka, India • Affiliated to VTU Belagavi

Smart Campus 360 is an AI-powered unified digital campus solution designed to elevate the student, faculty, and visitor experience across the campus of Government Engineering College, Mosalehosahalli (Hassan).

Integrated Architecture Principles

Module 1: Navigation

A* and Dijkstra graph-based shortest path calculation across multi-floor academic blocks, featuring interactive canvas map rendering, directional cues, and Street View-style photographic waypoints.

Module 2: AI Lost & Found

Visual feature vector extraction powered by OpenCV and cosine similarity distance metrics to pair lost items with found items across the campus registry, complete with verification audits.

Module 3: Smart Canteen

Advance food booking with automated Teacher-First Priority queue scheduling, live inventory deduction, QR code verification for counter pickup, and cancellation refunds.

Extensibility & Future Data Import

The database is structured to decouple application logic from campus geographical data:

  • Actual Photographs: Can be uploaded to /static/uploads/navigation/ and linked to node codes.
  • CAD Coordinates & Blueprints: Floor plans can be exported to standard PNG/SVG canvas maps and node coordinates mapped via the Main Admin Map Manager.
  • Department & Lab expansion: New buildings, laboratories, and seminar halls can be added dynamically without code modifications.
